# 智能助手 RAG 知识库

本目录为电力巡检智能助手的**检索增强生成（RAG）知识库**，存放 Markdown 格式的规程摘要、FAQ 与系统对照文档。用户在前端发起问答时，系统会按问题意图检索相关片段，注入大模型上下文后生成回答。

## 功能范围

智能助手可基于本知识库回答以下类型的问题：

| 能力 | 示例问题 |
|------|----------|
| 缺陷概念与分类 | 常见缺陷有哪些、严重等级怎么分 |
| 处置与消缺 | 污秽/鸟巢怎么处理、要不要停电 |
| 巡检与作业 | 无人机怎么巡、巡检周期 |
| 红外诊断 | δ 怎么算、红外怎么判 |
| 算法与复核 | 置信度、误报、复核策略 |
| 安全与应急 | 两票三制、安全距离、警示标识 |
| 系统对照 | 系统字段、RT-DETR 检测类别 |
| 标准摘要 | DL/T、GB 等行业标准要点 |

知识库未收录的内容，助手会明确说明并建议查阅企业规程或现场负责人，不会编造标准条文。

## 检索策略

1. **Query Router**：根据问题意图匹配 `category` / `topics`，缩小检索范围
2. **Hybrid 检索**：向量（TF-IDF 或可选 Embedding API）+ 关键词，经 RRF 融合排序
3. **FAQ 优先**：`doc_type: faq` 文档在同类问题中加权，提高常见问答命中率

检索结果作为「参考知识」注入对话上下文，由大模型组织为 Markdown 回答，并尽量注明标准号。

## 文档格式

每篇 Markdown 文首需包含 YAML frontmatter，例如：

```yaml
---
category: concept
doc_type: faq
question_types: [列举, 概念, 有哪些]
topics: [defect_class, visible, infrared]
tags: [缺陷类型, 绝缘子, 导线]
---
```

- 正文按 `##` 标题分节，单节建议 ≤800 字
- 标准摘要类文档应标明标准号与适用场景
- `_meta/` 目录仅作元数据索引，不参与检索

## 导入与维护

启动时自动加载 classpath 下的 `knowledge-base/` 目录；也可通过接口手动重载：

```http
POST /api/ai/knowledge/reload   # 重新扫描并入库
GET  /api/ai/knowledge/status   # 查看分块数量与索引状态
```

## 扩充知识库

1. 在对应分类目录新增 `.md` 文件，填写 frontmatter 中的 `category`、`topics`、`question_types`
2. 每节用 `##` 标题；单节建议 ≤800 字
3. 调用 `POST /api/ai/knowledge/reload` 使变更生效

标准来源与引用关系见 `_meta/sources-index.md`。
